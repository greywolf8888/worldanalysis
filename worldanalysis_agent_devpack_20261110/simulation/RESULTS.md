## 这次没有验证的事项

- 没有连接网站或百度网盘，没有调用 ASR/OCR/LLM，没有转存、下载或分析真实课程。
- 文件数、作者、内容指纹、图像数量和覆盖状态来自人工定义的测试 fixture，不证明 Agent 能正确发现或推理这些事实。
- 未实现真正的并发任务队列、HTTP Range 客户端、媒体解码、背压和 RAM/VRAM 压测；字节预算只验证策略与计数。
- 商业预算示例为内存内策略；生产必须把预留、DISPATCHING、未知提交与远端 task_id 持久化，不能把这个示例当作已经实现了持久账本。
- 发布恢复示例使用测试自建的临时目录与 SQLite；未验证多进程竞争、机器断电、跨文件系统、符号链接攻击、Windows 锁文件或操作系统目录 fsync 行为。
- 路径验证是严格“已解码 POSIX 路径”契约，不代表真实百度 API 的权限验证已完成。Range 200 时关闭路线的实际响应关闭动作，仍需真实连接器实现。
- 没有以这些测试替代真实课程验收，也没有据此宣布整个开发项目完成。

## 与生产契约对齐要求

参考模块仅演示谓词，不定义主项目最终 schema。主控可采用自己的字段名，但不得弱化以下规则：未知状态不得写成已核实；不同作者不得只因主题或文件名相似合并；作者联系方式不得自动删除；未授权路径和权限阻断不得通过更换工具规避；商业提交未知不得释放全部预留并盲目重试；证据发布与账本登记之间的中断必须可恢复且幂等。
