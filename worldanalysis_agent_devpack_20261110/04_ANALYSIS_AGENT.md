# 独立分析模块

## 输入与权限

输入只来自已发布 Bundle，带项目ID、源修订、blocks、图像、表格、联系人和缺口。分析模块无云盘写权限；需要补充就提交采集任务，不能直接扩大获取范围。

以用户已授权的通用模型/Agent运行时为主，不绑定某个行业专用模型。模型更新不改变原始证据、项目身份和分析契约。可在当前Agent辅助模式工作，也可后续接独立API。

## 阅读策略自动适应规模

- 一两份短文本：一次直接理解，生成简短可读报告，不建向量库，不运行媒体任务。
- 一组文档：按原目录与语义关系构建阅读计划；需要图像的地方实际打开图像。
- 长课程：以章节/原始块划分批次，记录每个主要block归属；重叠内容仅作上下文，不重复计覆盖。
- 每个批次输出事实、步骤、依赖、关键数字/术语、图像关系、作者主张、冲突和待核验项；不是只输出一段摘要。所有发现的证据块均登记已读/失败/待读/排除；“主要”仅用于阅读优先级，不允许静默丢弃其他块。
- 汇总基于可检索原块与事实台账，关键结论回读原文；禁止仅对层层缩短的摘要再次摘要。

首次理解不能只用top-k检索取几段代表全项目。检索更适合后续问答、回读和跨课程比较；需要全面理解时，所有非排除的证据块必须有已读/失败/待读记录。排除项保留理由、证据和可恢复入口，不计已读覆盖。页眉页脚、批注、备注和隐藏内容可不进入简版报告，但存在性、提取结果或未提取原因必须有记录。

## 通用核心与按需扩展

共同核心：目标问题、概念、先决条件、实际流程、输入输出、工具/材料组合、参数、失败模式、案例边界、作者/支持渠道、证据缺口。

领域扩展由Agent根据材料自动选择，可组合，不是固定用户表单：

- 学习：知识依赖、例题、误区、练习与复习顺序。
- 软件：版本、环境、安装前提、操作次序、参数、预期结果、排错。
- 业务：目标客户、交付、成本结构、获客路径、证据支持的收益主张、最小验证。
- 平台规则：作者当时说法、适用日期、当前官方规定、仍成立/失效/待核验条件。
- 研究：论点、证据强度、相反观点、待验证假设。

不能给一份解压说明硬凑商业分析，不能给没有收益数据的教程生成确定利润或成功率。

## 结论分层

每个重要结论标记为：作者明确陈述、从资料提炼、外部来源已核验、模型推断/建议、尚待核验。每项保留原block/页/时间/URL。外部资料不能被混写为课程原话。

不改写原始材料以消除矛盾；原数字/术语与纠正建议同时保留。涉及命令、金额、账号、联系方式、公式时，优先原图/原音交叉核对，无法核对就标不确定。

## 当前核验

对会变化且影响实际执行的主张按优先级搜索一手来源：软件版本与接口、平台政策、费用、服务可用性。稳定基础知识无需每段联网。记录检索日期、实际读过的来源、支持/反对/未找到；搜索没结果不等于事实不存在。

法律、医疗、金融等高风险材料需要更严格来源与专业边界；不要因为作者自称盈利就形成投资建议。用户要求合法项目不消除对内容本身的风险判断。

## 输出给用户

每项目一个主入口，可按规模输出：

1. 一屏/短篇导读：它是什么、适合什么人、先看哪些内容、目前证据范围。
2. 完整知识地图与步骤：前提→操作→工具搭配→预期结果→异常。
3. 学习/实操路线：可以立即做的最小练习或验证，依赖与停止条件。
4. 当前核验和拓展：变化、相反证据、可迁移原理；与原课程分开。
5. 联系人与原资料索引：归属、证据位置和不确定项。

短材料可以合并成几段；长课程提供总览与章节链接，避免让用户手工阅读四种重复报告。用户要求完整逐字稿时从证据包直接提供，不另生成替代性稿件。

## 迭代与跨课程

用户反馈/实践结果→关联原结论与证据→产生修订，不覆盖旧版本。新材料只影响相关章节/结论；模型切换不触发重新获取未变的媒体。

每门课程先独立理解。跨课程比较单独建立综合视图，保留不同作者观点，不把同主题不同作者误合并成同课程。

作者联系方式、公开支持渠道和分销方联系方式分别记录；同联系人跨多课程出现不自动是广告。同一无关引流包可被降低学习权重，但仍保留出处与分类证据。

## 可复用框架的边界

DocETL 的 map/reduce/resolve、预算统计可以作为分析批处理实现参考；关闭未预算的自动优化和模型切换。LangGraph 可在确实需要复杂分支/恢复时引入，必须用持久checkpointer，不把内存状态当断点续作。

RAG-Anything/LightRAG 可后续提供跨资料检索，构图/embedding仍会消耗资源，不是首期两文件分析的前提。NotebookLM类产品可作阅读对照端，不承担百度采集与完整证据交接的主责任。
