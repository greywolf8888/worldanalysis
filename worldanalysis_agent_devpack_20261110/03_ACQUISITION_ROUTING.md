# 采集与混合格式自动路由

## 1 统一决策规则

先识别来源与真实格式，再选最低成本可达质量要求的路线。格式、大小和“需要什么信息”共同决定路线，不能只按扩展名或项目标题。简单文件用确定性规则直接处理，Agent 只介入不明确的类型、关系和质量升级。

计划必须列出：证据依据、拟处理范围、provider、预计字节/费用/资源、后备路径、停止条件。程序先检查权限与预算，再执行。模型提出的计划没有自动提升权限的能力。

提取分四级：

1. 原生读取：TXT、字幕、Office XML、可读 PDF 文本、已有可靠图片/表格。
2. 本地结构化解析：复杂布局、表格、扫描页 OCR、页面/区域渲染。
3. 局部模型理解：流程图、公式歧义、操作序列、低置信难段；保留真实图像与文字定位。
4. 已批准商业备用：仅送必要页/片段，记录异步任务、用量、外发范围和返回产物。

不要把整个项目升级为最重的处理模式。某一页复杂，只升级那页或明确的上下文窗口。

## 2 网站到百度

- 先复用现有 wangzjk.com 文章索引与游标，增量读取正文、课程目录和授权下载入口。
- 普通页面优先轻量 HTML 读取；确需登录交互时才使用已被允许的浏览器入口。遵守访问限制与服务条款，不进行风控绕过。
- 保存文章介绍与资源正文的不同角色，营销介绍不能充当课程原文。
- 分享链接、提取码与资料密码放受限本地记录，不出现在公开报告和模型公共提示中。
- 递归、分页得到分享清单，整套项目关联后转存到授权目录。首次收到 submitted 只登记，不写完成。
- 转存超时：先用操作号查询或按目标目录逐项核对，不能马上重发导致 newcopy 重复文件。
- 目标读回必须检查实际文件、目录关系、数量与身份；混合格式一并登记，不仅筛 mp4。
- 当前权限/安全策略拒绝时，保留 blocked 和原因，不把浏览器拒绝改道到 CLI/API。

## 3 百度存储适配器的采用顺序

1. 当前已经正式授权且目录相容的接口/客户端通道优先。
2. 官方 Go SDK 作为文件层适配研究首选：可返回读取流，但 OAuth、应用权限和允许路径需真实核实。SDK 不是百度全功能通行证。
3. 已合法配置且平台允许时，可封装 BaiduPCS-Go；非官方兼容性由适配器承担，不当成解除安全阻断的方法。
4. 浏览器转存参考 transfer-helper 的分页/递归/退避；AI材料参考 baidu-ai-batch 的页面定位与导出。只借鉴经过验证的部分。
5. bdpan-storage 当前约束 `/apps/bdpan/`，与用户目录不相容；标记 `SCOPE_INCOMPATIBLE`，不自动启用。以后用户主动扩大授权才重新评估。
6. OpenList 仅在多网盘确有收益时评估官方下载模式，不启用绕过型模式。

已有百度文稿/笔记/课件是可选来源。默认不请求新生成；读取前确认有真实内容，不让每个视频因为不存在的课件反复排队。摘要不替代逐字稿；提取课件也不必然是作者原始 PPT。

适配器必须将read_existing_artifact与request_generation分成不同权限操作。只有已验证为纯读取的UI/API可以用于默认探测；打开标签、选择功能若会创建生成任务或副作用未知，不能以“看看有没有”为由点击。baidu-ai-batch的生成逻辑不得混入默认读取路径。无已有产物时返回not_available，远端生成任务数应保持0。

### 已明确选择的平台优先任务

用户在 2026-11-16 明确选择对既定目录先取得全部视频课件和文稿，再按缺口补采。这是[任务级路线更新](../docs/platform-first-20261116/README.md)：可使用本账号现有免费/会员权益生成这两类产物，仍须分开读取和生成回执、保留宿主授权检查，不购买、不充值、不自动启用外部收费 API。额度耗尽只关闭新增生成；账号、来源身份或宿主安全拒绝则停止任务，不能借补采改道。全目录第一遍完成之前不启动媒体兜底；已有产物覆盖未知时先复核，不无差别重转整片。

## 4 文档和附件路由表

| 输入 | 首选提取 | 必须保留/核验 | 升级条件 |
|---|---|---|---|
| TXT/MD/JSON/YAML | 原生解码与结构解析 | 原字符、编码、链接、键和值、来源 | 乱码、混合编码、模型难以理解的结构 |
| SRT/VTT | 字幕解析器 | 原时间、语言、字幕性质、缺段 | 明显截断、字幕与时长/内容不符 |
| DOCX | 原生/MarkItDown + OOXML媒体与关系读取 | 段落、表格、超链接、内嵌图片、题注；登记页眉页脚/批注/隐藏对象 | 图片指代未解释、复杂排版、公式/图形需要渲染 |
| 数字PDF | LiteParse 快速通道；若已有可靠解析器则先复用 | 页数、文本bbox、图像/矢量对象清单、页面关系 | 多栏错序、文字乱码、扫描页、复杂表格/公式 |
| 扫描PDF/图片 | Docling + 本地OCR，单页/小批 | 原图、OCR、页码/bbox、旋转/识别不确定性 | 中文/手写/复杂公式低置信，升 MinerU 或批准的服务 |
| PPTX | 原生结构 + 渲染/Docling | slide顺序、讲者notes、隐藏状态、图片、图表、形状 | 仅文字不足以描述流程图/叠加对象 |
| XLSX/CSV | 原生表格读取 | sheet、cell范围、值与公式分开、合并单元格、隐藏状态、图表/图片 | 公式缓存缺失、图表意义或复杂结构不明 |
| HTML/图文笔记 | 正文与链接结构 + 授权图片本地化 | 顺序、真实图片、题注、原网址、失效图片清单 | 懒加载/导出不全、图文对应不明 |
| 旧DOC/PPT/XLS | 已批准的 LibreOffice 等隔离转换后解析 | 原件、转换日志、字体/版式差异 | 无可用转换器、加密/损坏；不假报支持 |
| ZIP/RAR/7z | 先枚举再逐成员分类 | 压缩包身份、成员路径/顺序、合法密码来源 | 加密、solid压缩、目录不能枚举、资源预算不够 |
| 工程/模板/工作流 | 可读 JSON/XML/清单和伴随说明 | 节点、素材引用、参数、软件版本线索 | 二进制专有结构需原软件只读导出 |
| EXE/MSI/脚本/宏 | 仅登记配套用途和来源 | 名称、版本线索、风险与未执行状态 | 不在本项目执行或安装 |

Word/PDF 小文件优先直接取得原件。本地原生提取通常免去云端异步等待，并能取得其真正内嵌图片。原生提取或 Markdown 成功并不代表图片成功；必须单独核对视觉清单。

DOCX/PPTX/XLSX 本质容器也需要解压上限，不能把“不是ZIP扩展名”当安全。禁用宏、外部关系自动加载和嵌入代码执行。XLSX 公式值是缓存或计算结果需注明，不随意执行公式外链。

## 5 视觉证据保全

- 保存作者实际图片，不生成相似图片冒充证据。
- 区分嵌入位图、矢量图、由文字/形状拼成的流程图。仅导出位图会遗漏后两类，需页面/区域渲染。
- 同一图像资源可复用，出现的位置和上下文不能去重删除。
- 正文出现“如下图/见表/点击这里”而没有对应素材时，Agent 自动登记补采。
- 对软件参数、代码、公式、金额、联系方式保留可读原图，OCR/视觉描述只是附属层。
- 外链图片无法授权取得时明确缺口，不自动泄露登录凭据或放宽站点范围。
- 图片保存数量与预检发现数量对账；发现范围未知时记 unknown，不凭模型说“全部看完”认定齐全。

## 6 音视频最省资源的合法路径

依实际能力选择，不声称百度每个文件都支持：

| 已验证的源能力 | 执行路线 | 对资源的实际影响 |
|---|---|---|
| 可靠完整字幕/原始文字，视觉素材足够 | 复用并核对；不重复全量ASR | 减少转写计算与传输 |
| 独立音频轨 | 全音频转写 + 必要画面单独读取 | 可以显著减少音频取得字节，画面另计 |
| 源端低码率视频 | 选择仍可读的版本，一次读取分出音频和图像 | 节省输入字节，取决于真实源版本 |
| 只有音画混合原流 | 有界顺序读取，同时提音频和候选画面 | 节省长期磁盘，不保证节省原视频流量 |
| 有效Range/可seek/可定位分段 | 读取必要区间，记录实际返回字节 | 受HTTP、容器索引、关键帧依赖和权限约束 |
| 无可用流，只可完整文件 | 文件不超过批准缓存预算才临时取得 | 超预算 blocked_resource；不能静默占满硬盘 |

`-vn` 只控制输出，不保证网络只传音频；本地降至720p不降低已经传输的原始字节；抽帧频率降低也不必按比例减少输入解码。云盘是存储，不是任意模型执行服务器。

## 7 有界媒体 Worker

- 媒体读取器有界读入；同一个混合源尽量一次解封装，同时产生ASR窗口与画面候选，避免整片读取两遍。
- 外层起始窗口5分钟、短重叠2秒；仅为初始工程值，Agent按语言/资源校准。ASR模型内窗遵守其自身限制。
- faster-whisper 的 decode_audio 会将整个输入变成内存数组，所以传入 URL/file-like 仍需外层限窗。不能用“segments是生成器”宣称输入有界。
- SenseVoice 直接推理存在短输入限制，adapter内按当前模型约束切分；时间戳统一成全局毫秒，不混合秒/毫秒和旧版三元组格式。
- PCM仅当前窗驻留，长音频不得全转成float32数组。每队列有数量和字节上限，下游慢时上游停读。
- GPU默认只加载一个ASR worker；OCR先CPU，禁止ASR、VLM、文档大模型同时挤占6GB显存。保留系统余量，超过预算先降并发/批量/窗口，不丢内容。
- VAD减少无声ASR计算，但静音画面仍可含关键操作；VAD漏检/噪声段保存不确定标记。
- 转写重叠用时间与文本对齐去重，保留边界证据；术语词表来自该项目原始文件，不随意纠正作者意思。

## 8 画面策略

不是固定“每分钟一张”。低清小图做变化检测，证据图保持可读：周期保底 + 场景变化 + 局部文字/参数变化 + 语音视觉指向 + 静音操作变化。

PySceneDetect 是候选事件检测器，不是完整教学步骤识别器。只靠转场会漏静态软件窗口内的数字改变。必要时保存短片段而不是单帧；复杂动态操作可交已批准视频模型分析，但保留片段与时间证据。

视觉筛选有损，不能保证任意短暂元素都被抽到。以补采机制、覆盖声明和抽检约束风险；涉及关键执行条件却未取得画面时，不交付“步骤已核实”的结论。

## 9 自动质量检查与补采

程序检查：文件可打开、格式真实、页/slide/sheet枚举结束、时间区间有效、图片引用存在、截断标记、范围是否合法、成本是否超额。

所有发现的Asset/Block/图片出现位置均须登记处理状态。模型可安排优先级，排除也必须留具体原因、依据与恢复入口，排除不算已读。每个解析器输出版本、关键参数、预期页/资产数和实际结果；OCR插件未执行、只读前10页、图片开关未开启等必须partial，不得verified_complete。

模型检查：步骤缺前提、图文不对应、公式/数字冲突、只有概述没有操作、菜单/工具名可疑、作者与附件关系矛盾。每次升级必须说明缺口、最小范围、验证标准。

重试初始上限3次；同一确定性失败签名不重复。模型路线升级初始最多2轮；达到上限后保留可用证据和明确缺口，不无限等待。只有一次允许的链接刷新适用于确证的过期链接；权限拒绝绝不刷新绕过。

## 10 商业备用与费用

默认外发解析和新付费API禁用；不是禁止现有已授权Agent阅读它正在处理的材料。第一次明确外发范围和项目/日预算后，Agent在范围内自主调用，无需逐文件询问。

难文档先选一个已配置服务（推荐研究LlamaParse），难音频可用Qwen异步转写，难动态视觉可用支持片段输入的视频模型。禁止将百度Cookie、账号token或需凭证的私有URL直接交给第三方。必要音频上传到用户批准的临时私有存储并使用有限期链接，另计上传/存储费用。

提交前先持久化request_id/幂等键与预算预留；返回task_id后立即持久化。请求发出但响应丢失，记submission_unknown；有服务端幂等/查询能力才自动对账，无此能力不自动重发，由明确结果或必要确认解决。结果成功立即落盘。用量未回报为pending_usage，不能记0元；实际用量到账后结算，未知费用继续保留预算。模型不得因为备用更方便而自动启用新服务。
