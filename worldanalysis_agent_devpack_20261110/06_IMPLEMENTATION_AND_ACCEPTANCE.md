# 实施与验收

## P0 原工程接续和真实边界

只读检查旧数据库、代码、材料、授权通道、模型接口、设备内存/显存和磁盘。输出一页能力记录，不生成新的长计划。

保留发现索引、已有原始材料、可用文档提取和分析接口。给可修改的代码做正常版本管理；已有用户改动不覆盖。旧包中的浏览器安全阻断只能记为历史事实，须观察当前正式授权状态，不能推定仍阻断或已经解除。

验收：能列出本地实际材料与待办；每项能力分documented/implemented/verified/blocked；无账号或G盘访问就不声称检查过。

## P1 最短闭环：不含视频的混合资料

实现本地/已获授权的小文件输入→格式预检→正文+图片+表格→证据发布→Agent独立分析→主报告。

至少用真实短TXT、含图片DOCX、数字PDF和扫描页组合验证。短文本不得被100/500字阈值丢弃；图片未读取不得把文字转换成功作为整文件完成。

样本由Agent从当前已授权库存自动选取，不要求用户逐个提供或标注文件。暂时不存在的类型可自建明确标为合成的接口测试样本，但该类型的真实材料验收仍保持待完成，不伪装成生产样本。

验收：无需用户挑解析器，自动选轻重通道；一个项目可只有一份文件；每条关键结论能定位到真实材料。

## P2 网站到百度到本地

基于已有网站索引选一个有权限的真实项目，自动发现分享、清单、转存、目标读回，接入P1提取链路。先证实可用权限与目录，不先批量调用。

验收：文章不是教程全文；submitted不是完成；目标目录之外无文件操作；未知任务先核对不重复转存；混合文件和子目录均有状态。

若真实网盘访问受阻，只报告该项阻断，并继续P1/P3可使用的本地材料；不伪造成功、不换通道绕过。无需用户提供文件类型和技术方案。

## P3 有界长音视频

实现一个媒体读取器、一个ASR和复用OCR；增加源能力探测、限窗、背压、断点、候选画面与局部补采。真实小样本测资源后，再用授权课程逐步扩大。

验收：无整片float32数组；混流不误报只传音频；缓存有上限；同时需要语音和画面时不无理由重复全读；静音操作不因VAD丢弃；每个窗口和缺口可追溯。

## P4 自动运营与独立分析

采集和分析分别启动/停止/恢复。分析器领取Bundle版本、输出结构结果并通过程序校验；通过补采请求闭环，而不是直接拿云盘权限。

实现项目隔离、同作者内容/版本去重、联系人保护、事件驱动增量。后续再增加第二网站；增加来源不改分析器接口。

验收：不需要用户逐文件分类；已有可用章节先分析；换分析模型不重新采集未变资料；同主题不同作者仍保留不同项目。

## 验收场景

| 场景 | 必须观察到 |
|---|---|
| 只有两句说明TXT | 正常保留，识别可能的密码/前提，不创建视频任务 |
| Word有3张关键图 | 图像真实文件、段落关联与读取状态均存在 |
| PDF一半数字一半扫描 | 页级路由，不把全PDF一律重OCR或漏扫描页 |
| PPT含隐藏页/讲者备注 | 被登记并按内容决定是否分析；不静默丢失 |
| Excel含公式/截图 | sheet/cell定位，公式/缓存值区别，截图独立处理 |
| 百小时媒体 | 内存不随总时长线性增长；真实字节/ETA/缺口可查 |
| 没有课件 | 主线继续，PPT状态unsupported/absent/unknown不混淆 |
| 已有百度摘要但无逐字稿 | 摘要标派生，不能冒充语音全覆盖 |
| 网络断开/进程重启 | 查产物与任务ID后仅续失败窗口，不重复付费/转存 |
| 相同作者相同内容改包名 | 源关系追加，证据复用；无法确定时不强行去重 |
| 不同作者同一主题 | 独立保存，综合比较不吞掉作者观点 |
| 联系方式/跨课程重复附件 | 保留出处，疑似推广标记不自动删除 |
| API预算为0、未允许外发 | 不发送任何新商业请求；可用本地工作继续 |
| 明确权限/安全策略拒绝 | blocked，不尝试替代接口达成同一被禁止读取 |
| 加密/损坏/不支持的资料 | 明确原因，不生成伪正文或伪图片 |
| Range请求被服务器忽略返回200 | 探针立即止读；不全量下载、不误记支持Range |
| 商业请求已发送但响应丢失 | submission_unknown，保留预算，不自动再次收费提交 |
| 证据目录重命名后数据库提交前崩溃 | 按publish_id对账恢复，仅发布一次，分析不读半成品 |
| 旋转扫描页/裁切图跨解析器交接 | bbox单位、原点、尺寸与变换一致，不截错区域 |
| 云盘文件被移出授权目录 | 下一次操作重新校验路径并拒绝；不同分享ID不串用 |
| 百度AI标签可能自动生成 | 不作为read-existing探针，默认生成请求数为0 |

## 完整性不能只用一个百分比

分别记录：清单已枚举范围、正文页/块覆盖、语音时间覆盖、视觉采样策略/缺口、已解释图像、未核验主张。无可靠总量就unknown，不以最大时间戳/总字数倒推100%。

自动检查关键数字/步骤/联系方式，抽查不能证明零遗漏。阶段报告允许partial，但必须把未覆盖内容放在明显位置。

## 错误处理

| 错误 | 自动行为 |
|---|---|
| 确认的暂时网络/限流 | 有限退避，遵守Retry-After；不并发轰炸 |
| 确认签名链接过期 | 在原授权通道刷新有限次数 |
| 权限拒绝/站点安全阻断 | 立即blocked，不能路由到另一工具绕过 |
| 当前provider不支持格式 | 在已批准注册表选择另一个可用provider |
| 输出截断/缺图 | 对指定页/块/区间补采，保留已有产物 |
| OOM/缓存将超限 | 先降并发/批量/窗口，仍不满足则blocked_resource |
| 远端已提交但结果未知 | 持久记录/查询/对账，禁止盲目重新提交 |
| 商业预算不足/外发不允许 | 尽量本地继续，仅该动作等待授权 |
| 同一确定性错误反复发生 | 停该任务并记录最小可复现原因，不无限重试 |

## 资源初值与校准

`config/policy.example.json`里的数值是保守起点，不是性能承诺。Agent自动检测设备，RAM/显存/空闲磁盘分别测量；6GB指显存，不猜系统RAM。

音频工作窗、OCR页批、下载缓冲、临时缓存、最终证据容量必须分开。临时缓存超限不允许删除最终关键证据。必要证据超过最终空间预算时暂停相应发布，报告所需空间，不能静默降质。

## 维护和依赖准入

每个采用的provider写实际版本、上游URL、许可证/权重许可、能力实测日期和一个最小契约测试。固定验证版本，不自动追最新；不能把本包记录的README/提交快照直接当pip可安装版本。

不引入多套冲突的任务台账，不复制全部上游代码。只封装调用边界与补丁。升级先做小样本对比，保留上一可用版本，不在全量任务中途升级。

## 交付记录格式

每阶段只需：真实做了什么、代码/产物位置、资源和费用、缺口/阻断、下一项可继续动作。离线模拟、合成素材、真实本地资料、真实网盘资料四种证据分开标记。
