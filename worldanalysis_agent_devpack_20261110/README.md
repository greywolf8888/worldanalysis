# Worldanalysis 混合资料采集与独立分析开发包

版本日期：2026-11-10，Asia/Singapore。用途：交给现有本地开发 Agent，在原工程上实施，不是已安装的软件。

## 顶级意图

用现有家用设备和已经授权的来源，把网站、百度网盘或本地输入中的整套混合资料，自动变成紧凑、可追溯、可复用的证据；再由独立通用模型理解原理、步骤、条件、工具组合，进行当前核验和学习/实践拓展。输入可以只有两句 TXT，也可以是 Word、PDF、图片、表格、工程附件和数百小时音视频的组合。

采集负责取得和证明材料；分析负责理解和拓展。Agent 自行识别材料、选路、诊断缺口、有限重试，不把常规技术判断交给用户。权限、预算、文件真实存在和完成状态由程序检查。

## 交给开发 Agent

先读 `AGENT_START_HERE.md`，随后按 `06_IMPLEMENTATION_AND_ACCEPTANCE.md` 实施。默认复用已有 Python、SQLite、文件目录和任务接口。只有实测证明不合适才替换；不把全部候选项目装一遍。

本包修订旧 V2/V3 中“视频优先、百度 AI 四标签优先、无图片也可完成”的倾向。已有代码、索引、材料和历史记录保留；本包不是删除旧工程的授权。

## 证据与完成范围

- 本轮完成公开源码/官方文档研究、旧开发包只读复核、接口设计与离线模拟。
- 没有访问用户 G 盘、登录网站/百度账号、转存资料、安装模型、购买服务或运行真实课程。
- 旧记录中的 12,588 个网站入口证明历史发现规模，不证明课程全文已取得。
- 11 月 8 日的历史审计记录提到 075/163572 课程已有 78 份文稿和 12 份 PPTX、785 张页图。本轮原 ZIP 不在现有工作目录中，未重新核验这些材料，不能把历史数字标为当前库存。
- 实际可复读的旧包为 `worldanalysis_codex_v3` 和 `windows_pipeline_v2`，其中权限阻断和能力缺口必须由本机 Agent 按当前环境重新核实。

## 成功定义

用户投一个项目入口后，系统自行建立材料清单、选择有效通道、保存正文和关键视觉证据、标清缺口，输出能直接学习和实操的主报告；中断可恢复，重复来源不重复处理，小文档不等待长视频，分析模型可更换而不重新采集全部资料。

不以模拟通过、按钮点击、HTTP 200、文件非空或模型自评来替代真实项目验收。
