# Worldanalysis 教材归档与保全

## 职责与收件

- 总控负责项目代码、网页、分类规则和交接。专用 DSH 完成接管验收后负责子站采集，按站点保留原介绍、封面、发布页和实际资料入口。百度网盘的核对、转存、下载和清理由专用 DSH 执行。
- 人工来件和下载实收按稳定项目及版本身份入同一收件流程。先核真实来源、实物与范围，再加入分析队列。各项目及不同版本独立保存。用户提交的确认范围和既有任务版本随交接保留。
- DSH 项目内运行和跨主机迁移分别核验。专用会话、目标账号、路径、任务及回执使用部署环境绑定。平台登录凭据留在正常应用的会话存储。

## 分类与教材

- 按实质教学用途归入一个一级业务主题，平台与历史分类用于筛选和检索。依据不足时保留资源入口，留空分类。正式移动教材前预检旧链接、同名入口、独立回执与批次身份。
- 每独立项目交付一篇同名 Markdown。重要操作紧贴原图与相应时码。无声操作核全时轴，十分钟内可简洁整理，较长视频分段查动作与结果。两者默认保留完整原片，正文附相应用途入口。
- 必要模板、原文和原格式随教材保全。文字阅读版从实际用途打开，查完整性、复制和章节跳转。独立测试从原件查漏，再核正文、附件与实际跟做。核心待补版只呈现真实已收且通过验收的范围。

## 空间与清理

- 以所在储存卷的可用空间与下一批预计占用触发预检。核对当前版本、已签收教材的独立阅读、保全指纹、引用关系和当次对象授权。
- 先完成本地保全及结果读回，再单独确认可处理的云端对象。保留必要原件、未知范围、尚待回源材料和恢复证据。每次记录真实处理范围和实际释放空间，按当前数据决定后续步骤。
