# 专用 DSH 业务操作

1. 按[专用 DSH 手册](../../../docs/专用DSH运行与接管.md)核对当前专用接收端、旧入口、账号、目标、空间与任务状态。采集先读断点和正常授权会话，沿单一启用入口保存原介绍、发布页及实际资料入口。
2. 只处理已确认的项目、版本、顺序及范围。核对当前账号、分享对象、实际资料范围和容量。转存后核实远端实物，下载后核实收件文件、稳定状态和身份，再通知分析。
3. 使用原 `_exchange` 任务与回执。登录失效、平台要求验证、范围变化或副作用未知时保留断点，按正常入口核实后续作。再次领取前读回历史结果。
4. 网盘清理沿[保全与清理规则](../../../docs/收尾实施与教材归档规则.md)验证本地保全、同版独立签收和当次云端授权。课程生产及独立验收各沿指定角色执行。
