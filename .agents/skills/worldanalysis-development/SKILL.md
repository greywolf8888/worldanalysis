# Worldanalysis 开发与验证

1. 读[项目规则](../../../AGENTS.md)和部署环境中的生产接力。比较 GitHub、项目代码、正式课程工作树及在用服务，记录当前版本与配置绑定。
2. 找到现有入口和实际故障，确定正反例、证据及回退文件。在项目内独立目录用同一样本复现旧行为，再改最小范围。课程正文与网盘状态由对应角色操作。
3. 用已获授权的原件切片、隔离副本或只读业务数据复验。保留实际输入、命令、结果、时间和样本限制。用未参与调优的样本复验。
4. 网页改动按桌面和窄屏的实际操作顺序核对。交接改动核权限、版本、旧回执、重复提交和断点。有副作用的步骤超时后先对账。
5. 更新[操作与验收指引](../../../docs/全链路升级实施与验收.md)和本地接力，分别记录代码验证、实际服务版本与正式业务验收。
