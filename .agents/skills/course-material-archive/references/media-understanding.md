# 媒体回查

- 用 [现有工作流](../workflow.md)确定完整音画时间范围。沿用同源连续 PCM、字幕、原画与缓存。黑屏走全音轨，静音段查实际画面。首尾、分块接缝、单位、否定词、快捷键及冲突处回听原声。
- 录屏先查看时间轴与界面变化，遇到短暂菜单、光标或选区变化、滚动、弹窗与小字，按实际起止用 `window` 局部加密并核清晰原图。对完整跟做需要的状态保留动作前、执行中和结果。用同处隐藏时码定位关键图和参数。频率、差异和 OCR 只帮助找画面。
- 分开记录原声、字幕和界面所显示的数值及前提，标出待核冲突。确认无讲解后按原片长度分流，默认 600 秒内全时轴简洁图文，较长原片分段完整分析。两者均默认保留完整实物，入口贴近相关动作。
