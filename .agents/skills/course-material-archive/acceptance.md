## 本地教材验收

写稿前用 `coverage <课程包> --write` 保存原件核查范围。在独立对照原片和附件后，用 `preview` 获取同版 `.course/work/验收填写模板.json`，将实测结果另存为 `验收记录.json`。先执行 `check-review` 检查双向核对，再用 `accept` 执行同版发布验收。

**区分来源可得性和分析验收。** 对新稿必须在预览前声明本次收到范围、状态和外部缺件。`完整验收`、`配套待补`、`核心待补`均要求同样严格的全部已收到原件双向核对、同版事实核验、作者渠道检查、关键图与原件定位、真实 Obsidian 重开与批次登记；状态不得改变或降低这些检查。缺件仅指尚未取得的独立材料，而不是已收原件漏核、未读、不可读、未进正文或事实错误。非核心外部缺件不阻塞当前范围的验收与发布；核心缺件需醒目标明未完成的实际课程范围，只验收已经收到的全部内容。只含指引/推广、无可核独立教学内容不得按任何范围状态发布。缺少外部结果凭证时如实区分教师主张和已核事实，不要求实际执行或制造结果。历史签收不自动标成新版完整，补料更新同名教材并重新核验。

在 `.course/work/范围验收.json` 填写以下结构（这是字段示例，必须用本项目真实原件位置、正文短句和实际观察替换，不能将示例作为核查证据）：

```json
{
  "scope_status": "配套待补",
  "scope_gaps": [
    {"item": "作者另提到的独立参考素材", "kind": "非核心", "source": "第 1 讲 02:00–02:12", "impact": "本课方法在已收视频中完整演示；无法逐像素复现该参考样例", "obtain": "取得作者同版原素材后核对并更新原篇"}
  ],
  "scope_teaching": [
    {"source": "第 1 讲 00:30–00:52", "anchor": "实际教材中可见的教学短句", "observation": "在原件和对应正文核查到的实质教学，不是链接或推广"}
  ],
  "scope_resolutions": []
}
```

`scope_gaps` 无条目才能声明 `完整验收`；有任一核心缺件即 `核心待补`，只有非核心缺件为 `配套待补`。源位置采用本稿实际的隐藏出处标签形式（如 `第 1 讲 00:30–00:52` 或模板中的实际附件定位）；挂载外部说明写明已核出处及影响。`scope_teaching` 指向真正能教学的已收音画或附件及对应正文，必须实际回看，不能凭文件扩展名或自行断言。预览程序生成醒目的范围说明；范围变更会改变同版验收及独立核验身份，重新生成、独立检查和重开。

历史已记缺件不能通过删除数组消失。以前明确缺件在本版取得/核实、证实非真实缺件或证实属于非核心时，逐项填写 `scope_resolutions`：`item`（原缺件名）、`source`（当前核实定位）、`resolution`（`已取得并核实`、`经复核原缺件不成立` 或 `经复核改为非核心`）、`note`（具体实证）。未到手但改判非核心的条目仍在 `scope_gaps`。对原审计自由文字的逐项处置亦保留真实核对，不伪称齐全。独立测试同时检查收到内容、范围总判定、每项缺件、实质教学证明和旧缺件处置，回执须用同版待查文件的 `scope_acceptance` 字段填写具体观察和各项结论；不能只核关键事实、不核范围。

- **独立原件范围。** 逐个处理 `source_scope` 列出的所有已收时间窗、附件页、工作表、档内成员和作者线索。固定时间窗用于定位，还需按实际教学内容细分。有教学意义的段落逐条登记，资料可用而教材缺漏时先补正文。对无独立教学的来源说明实际看到了什么及其用途。仍有未取得的独立原件或归属证据时，声明收到范围和具体缺口并继续已收原件；`source_coverage` 中的已收原件缺口仍为阻塞，不用范围声明绕过。
- **发布正文反查。** `source_coverage` 将逐段、逐页核实的结果与可见正文及相邻的隐藏出处关联。`claims` 逐块记实际核对结果。讲师主张、原例和参数回到对应原件，编辑衔接、整理示例及外部核验各按其实际身份记录。修订后对照新模板回查变更位置。
- **同版关键事实。** 新稿预览产生 `claims_version: 3`。`paragraph_sha256` 绑定该段全部可见文字、原件和外部出处，不能用段首摘要代替。`critical_values` 自动提示快捷键、尺寸、百分比和 URL 的逐项位置。金额、单位、否定、条件、责任人等其他关键事实也由分析和测试人员主动核查。`fact_checks` 中每项填当前段唯一可见短句 `anchor`、`origin`（原件、外部或整理示例）、`source`（同段隐藏出处中的一个实际原件定位，或精确外部 URL）和具体核对结果 `note`。同一证据可覆盖多个明确值；指纹和程序只证明本次核对绑定到了哪些文字，实际正确性仍须回查来源。
- **混合和外部来源。** 公开资料纠正原课时，正文说明讲师说法与来源方核验结果；在对应段追加 `<!-- 外部出处 https://实际来源 -->`，多个网址分开注明。仅外部事实用 `外部核验`，混合原课及外部事实用 `混合来源`，各自填写精确短句和真实依据；作者随课入口如果来自原件，仍归原件。历史正式回执按旧正文指纹继续可读，修订和新发布须走新版校验。旧记录只有完整旧正文、原出处及证据未变时可以辅助复核，变更段和关键值重新核证，不能手工改写摘要或指纹冒充复核。
- **独立测试签收。** 作者填完新版 `验收记录.json` 后执行 `fact-review-template <课程包>`。入口生成 `.course/work/独立事实核验待查.json`，里面的同版正文、原件范围和事实行指纹固定；这份待查清单没有测试结论。测试 agent 从实际原件和外部原文逐项复核候选短句与来源关系，填写 `reviewer.role` 为 `测试agent`、`thread_id`、带时区的 `reviewed_at`，以及每项实际 `observation` 和可追到原件/原页的 `evidence`。已有单独证据文件时可附 `evidence_files` 中的项目根相对 `path` 和 `sha256`，发布时再核指纹，不需复制整套原件。全部实际成立时在每项与顶层填写 `decision: 通过`，将回执按清单的 `receipt_path` 写到 G 盘独立回执目录。作者不能代填测试证明。修改正文、来源或作者事实核对行后，旧回执不能复用，须重新核对变动事实并由测试 agent 为当前版签收。同一计算机的角色隔离依赖真实工作交接和总控核查，程序不证明两个代理具有独立权限。`check-review` 和 `accept` 对有事实项的候选均检查独立回执，正式回执内存入同版核验记录以便历史复验。

- **每集处理和首尾。** 在 `episodes` 保留原片登记号 `lesson`、可见讲次 `display_number`、原片路径、指纹和对应二级标题。`watched` 按时间覆盖原片首尾，分段记录实际核对到的教学、原例、说明或过场。时码、候选图和检测数量用于定位。确认有声覆盖、硬字幕、暗画面、纯画面与长停留界面分别读到了什么。填写 `audio_checks`，记录已补项和真实听辨缺口。纯文档的 `episodes` 为空。
- **原课内容到正文，再反查。** `source_points` 从独立的逐段要点文件载入。给每项对应有该段隐藏出处的可见 `anchor`，或者用 `source_limit` 说明原件实际缺了什么。检查关键结论在相邻的原片区间或原附件页是否成立，再反查同名案例有没有串用数值、公式列、分母、顺序、配比或结论。复核既有教材时，从完整原件范围出发并回写真正新增的要点。缺内容时回改正文并再核对，版本不清或不确定的结果保留准确范围。
- **动作要看得到。** `key_steps` 记录起止秒数、可见句子和紧接的图片。同一短句也出现在标题或其他段落时，用该步骤正文里的隐藏时间出处定位。检查候选中重复的停留画面、跨文件重复片段和无教学用途的过场。近似界面原图应逐张确认光标、参数和操作状态是否有不同用途。`visual_basis` 及 `visual_note` 写清原片、同课附件或没有可教学画面的依据。只看到黑底对白时可选原附件或用注明身份的整理示意图帮助跟做。观察记录、已采用的复识与实际看过的原图可在 `checked_sources` 登记工作区相对路径和 SHA-256。
- **跨讲复用同一画面。** 分别核对两集的原声和原画。第二集只有同一幅教学画面时，正文在相关说明旁链接本篇前面已插图的章节，保留第二集自己的时码和新口述。用 `visual_basis: 复用同一原画` 和 `shared_visual` 登记前一处配图与本集原片对照。本集出现新的指示、参数或结果时，在相应动作旁加本集原画。
- **附件去向。** `documents` 逐件用 `inspected_at` 记录实际检查的页、工作表、档内成员或文件部位，再写用途和判断依据。引用的附件核到具体位置，按需贴原图。损坏或未能提取的资料说明实际尝试的入口和对跟做的影响。
- **PDF 链接。** 逐页查 `pdf_hyperlinks` 和原画里的链接文字、截图署名及裁切位置。遇到跨行或截断的项目入口，登记原页读到的字样，核到完整账户与公开项目才补入口。同一参考链接只放一个阅读入口，隐藏定位仍可追到原页。写清能读到目录、正文或需要权限的范围，以及作者页面上的版本与原包是否一致。
- **独立网址与隐藏链接。** 逐项核对附件独立一行的网址，包括缺协议的明确域名，也核对仅在 PDF 点击区域里的网页地址。区分讲师或作者入口、随课模板、案例和分发推广。跟做需要用到的链接写明用途并放在对应步骤附近。公开可达、需登录、需另外授权和已取得原件分别如实登记。
- **Office 链接和原例。** 核 Word 显示文字与实际点击目标、Excel 链接的真实单元格与同一行的原案例，以及幻灯片点击区域与原页。对旧格式或提取不出点击目标的情况，回到原件应用或可读副本核查。课程样本在正文说明它要比较的变量和结果，再提供原入口。
- **旧版 Word 的原图与规则。** 逐条核附件正文、文本框和 `picture` 单元。可用的截图或讲义用原 DOC 的图号取图并紧跟相关段落，正文的隐藏出处注明「第 N 幅内嵌原图」。同一图在原件多处重复的，用资料记录中的源流和位置核其对应关系。无法读到的图保留具体缺口。
- **幻灯片中的视频。** 核对 `episodes` 中的 `embedded` 字段、父文件、页码和成员摘要。查看音轨全范围与原画操作，完成该段的 `watched`、关键步骤和配图。引用父附件的静态页面时，仍在 `documents` 中逐件登记。
- **配套材料与学习支持。** 以完整附件、档内成员和视频中的作者说明补查原稿。逐集填写 `channel_review` 的 `opening`、`closing`、`screen`、`finding`，记录实际时码、画面位置与归属判断。有录像时同时检查口播和边缘小字。逐件记录哪些内容已讲清，哪些需要补充、重复归档、归属待核或另有未随课交付的文件。作者联系、资料自署和分发方渠道按对应原件判定。确认有读者价值的配套条目写入 `.course/work/补充内容复核.json`，每项登记正文短句 `anchor` 和同段隐藏出处 `sources`。逐项核阅预览生成的 `supplements`。确认没有独立补项时，这一列表可以为空。
- **仅在画面里出现的联系。** 多时点检查移动、倾斜或受遮挡的角标。将核清用途的联系放入对应时段的 `findings`，标为 `作者渠道`。有完整可读的账号或网址时填 `value`。验收要对上可见正文里的标识及同段隐藏出处。仍辨不清或不能归属时，记录读到的内容和待确认原因。
- **课内答疑。** 原声只说在课程群问值班老师、向带班人领取模板，也要保留已确认的去向、用途和学员范围。复看邻近原画确认主体；公开账号未提供时，按原课说明写出课内路径，并登记缺少的入口或独立文件。
- **只读跟做。** `follow_along` 里用同一节正文的输入、入口、参数、成品和修正作定位，来源指到该节的隐藏注释。检查读者能否解释方法、按变量演算、依图操作并判断适用条件。讲师亲历、编辑示例与学习者动作各有明确身份。读稿走查、实际运行软件、实物验证和真实学员反馈分别按实际做过的内容记录。
- **教学编辑。** 合并重复讲解后，把原来的独立要点、数字、条件、案例和关系一项项回查。用原件路径与时间对齐正文、隐藏出处、配图和索引，换讲序时保持原片身份不变。制作过程记录放进来源区或工作区。
- **课程包版本和展示。** `accept` 核对原件、时间轴、关键信息和图的紧邻位置，再用隔离 Obsidian 阅读视图检查图片、页尾、折叠和引文。正文、配图或证据变化时，重新生成预览并核对受影响的内容。
- **日常阅读入口。** 在用户实际使用的库沿用旧课目录，每个项目只有一篇以项目名命名的教材。`deliver` 返回 Obsidian 直达链接。`verify-reader` 从实际入口读取同版文件，在独立 Obsidian 环境重开并查全部章节、邻图、页尾和隐藏出处。`confirm-vault` 可登记实际窗口观察。`verify --require-vault` 校验现存正文、原图、链接原件和重开记录。完整验收同时需要课程包和日常入口两项。具体字段和命令见[开发文档](../../../docs/课程资料整理与%20Obsidian%20教材制作手册.md)。
