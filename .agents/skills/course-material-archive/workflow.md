## 本地教材工作流

下列命令均从 Worldanalysis 根运行，使用脚本回报的实际课程包路径。完整参数、目录与数据结构见[开发文档](../../../docs/课程资料整理与%20Obsidian%20教材制作手册.md)。

1. **入库并复用可用成果。** 执行 `course.ps1 start "<原件文件夹>"`，用 `.course/ledger` 的原件、媒体和附件清单确认范围。依开头、目录和上下集衔接校对 `讲次顺序.json`。`媒体设置.json` 可指定语言、音轨、原字幕与同版有声件。原件和配置未变时用 `prepare` 恢复处理。若可用字幕只概括了操作，保留它并对照全音轨转写和区间内文本差异。
2. **取材到片尾。** 用 `read <课程包> <讲号> --start <秒> --end <秒>` 取时间窗。对数字、否定、短指令、专有词、分块交界或缺失语音回到原音，必要时指定 `refine --lesson <讲号> --range <起秒> <止秒>`。保留原版本和复识输出，有原件依据才用 `adopt` 改 `采用转写`。参考声轨只有一段时按片段继续视觉取材。音频候选及阈值以下区间仍需结合内容判断。
3. **核视觉与附件。** 对讲解与界面互补、无声、硬字幕、暗色画面分别选时段。短暂菜单、光标圈点和前后状态用 `window` 回查。长时间同屏用 `observe` 按原始时间排序打开局部图，硬字幕可裁字幕带加 `--ocr`，逐项核 OCR 的时码、小字和数字。纯画面只讲能看到的动作和产物。先看原片或附件页图，再以 `keep` 登记原像素，整理示意图标明身份。PDF 分页，表格查原单元格，图和公式放在实际动作旁。
4. **先列来源要点，再写一篇教材。** 在 `.course/work/逐段要点/<讲号>.json` 逐段记概念、输入、动作、条件、参数、原例、纠错与结果。先做来源清单，再对照旧稿去重、修缺项。写 `.course/work/教材.md`。每个视频有对应二级标题，长讲用三级标题分清动作。纯文档任务按原材料顺序组织。正文把教师的方法讲到学习者能照做，并在动作旁放关键截图、页图或有来源的示意图。
5. **预览、逐集复核、发布。** 用 `preview` 生成当前稿，先从原件逐段看是否漏，再从正文反查出处，只读跟做到产物。将实际范围和缺口记在 `验收记录.json`。`accept` 检查同一版的内容定位、原图和真实 Obsidian 阅读，通过后发布到 `课件/00 开始学习.md`。`verify` 核对发布物和原件。中断时记录最后一个已核讲号和范围，用原包恢复。

### 本地教材编写提示

> 先确认这一讲要做成什么，用老师第一人称按原教学顺序带做。「我先打开……」「我填……」「我保存后看……」要接着讲真实的对象、入口、设置、可见结果和卡住时怎样修。原案例和老师实际看到的产物写在发生位置。需要可复制的提示词、表格字段、公式或输入就在正文给出。口述值与附件单位有差异，核查原件并注明实际适用条件。自拟的练习标明「练习」，课堂没提供的前置条件写在实际用到之处。
>
> 做教材时用 `{{02|03:15–03:42}}` 记录原片区间，用 `{{D003|Sheet1 C4:O6}}` 记录附件位置。紧贴动作下一段用 `{{img:原图文件名去后缀|550}}` 插图。取图应看得清操作入口、有效值或结果。让段落与图的出处由发布器写进注释，原件入口默认在文末收起。正文以一篇完整学习内容连续往下展开，版本、提取和选图过程随台账保存。
