## 本地教材工作流

下列命令均从 Worldanalysis 根运行，使用脚本回报的实际课程包路径。完整参数、目录与数据结构见[开发文档](../../../docs/课程资料整理与%20Obsidian%20教材制作手册.md)。

1. **入库并复用可用成果。** 执行 `course.ps1 start "<原件文件夹>"`，用 `.course/ledger` 的原件、媒体和附件清单确认范围。复核旧课时先拿用户给的完整来源目录对照旧入库清单，再核新增文件的开头、授课目录、结束话语与相邻片段。录制切分重叠时把两个原件和实际重叠时间登记，重复内容在正文讲一次。缺少同课依据的文件保留待判。依原课顺序校对 `讲次顺序.json`。`媒体设置.json` 可指定语言、音轨、原字幕与同版有声件。原件和配置未变时用 `prepare` 恢复处理。若可用字幕只概括了操作，保留它并对照全音轨转写和区间内文本差异。
2. **取材到片尾。** 用 `read <课程包> <讲号> --start <秒> --end <秒>` 取时间窗。对数字、否定、短指令、专有词、分块交界或缺失语音回到原音，必要时指定 `refine --lesson <讲号> --range <起秒> <止秒>`。保留原版本和复识输出，有原件依据才用 `adopt` 改 `采用转写`。参考声轨只有一段时按片段继续视觉取材。音频候选及阈值以下区间仍需结合内容判断。
3. **核视觉与附件。** 对讲解与界面互补、无声、硬字幕、暗色画面分别选时段。短暂菜单、光标圈点和前后状态用 `window` 回查。长时间同屏用 `observe` 按原始时间排序打开局部图，硬字幕可裁字幕带加 `--ocr`，逐项核 OCR 的时码、小字和数字。纯画面只讲能看到的动作和产物。PDF 分页，表格查原单元格、嵌图和公式。PPTX 的文字、形状、截图共同提供信息时查看完整渲染页。对附件提取缺口逐件记录原件、实际查看部位、有无新增教学以及缺失时的原因。先看原片或附件页图，再以 `keep` 登记原像素。整理示意图标明身份。
4. **先列来源要点，再写一篇教材。** 从实际片段和附件定位，在 `.course/work/逐段要点/<讲号>.json` 逐段记概念、输入、动作、条件、参数、原例、纠错、结果和关系。按来源独立排查行业逻辑、盈利来源、执行失败和课后问答，再对照旧稿去重和补缺，旧索引只作查找入口。每条参数保留其案例、分母、时间窗和前后条件，教师估算或个人主张用原身份写。外部核验、编辑解释和自拟练习注明各自身份。写 `.course/work/教材.md`，每个视频有对应二级标题，长讲用三级标题分清动作，在动作旁放能直接支持它的原图或注明身份的示意。
5. **预览和逐集复核。** 用 `preview` 生成当前稿，先从原件逐段看是否漏，再从正文反查出处，只读跟做到产物。将实际范围和缺口记在 `验收记录.json`。`accept` 核对内容、原图和隔离的 Obsidian 阅读检查，产出已验收课程包。
6. **更新日常 Obsidian。** 确认正在使用的库、同课原入口和已有编辑。首次用 `deliver` 绑定并更新该入口，已绑定的课程由 `accept` 更新。确认本地资料仍按用户约定留在本地。去实际库重开同一篇，核新版章节、步骤旁的图片、隐藏出处与折叠到页尾，用 `confirm-vault` 留下观察，再跑 `verify --require-vault`。中断需分别保存已完成的课程包版本和日常库核验进度。

### 本地教材编写提示

> 先确定学习者这一节要解决什么问题。理论讲依据、原因和边界，案例把背景、选择和结果连起来，公式用变量、单位、算式和演算展开，操作把入口、状态、动作及结果连起来。讲师的亲历明确归给讲师，课堂原话可具名引用；学习者的动作直接引导，自拟输入和产物标为「演算示例」或「练习」。多个来源说明同一问题时合并讲解，新增的条件、分支、数字和失败经验保留。影响使用的限制留在相关段落，拼接、校对和取图记录留在工作区。
>
> 用 `{{02|03:15–03:42}}` 记录稳定原片编号与文件内时间，用 `{{D003|Sheet1 C4:O6}}` 记录附件位置。发布时段落出处、配图出处和文末索引使用同一阅读讲次，并保持原片时间不变。紧贴动作下一段用 `{{img:原图文件名去后缀|550}}` 插图，说明图帮助找到的入口、核对的状态或解释的关系。原片字幕能支持术语或数值，界面原图才用于确认控件。正文连续呈现，原件入口默认在文末收起。
