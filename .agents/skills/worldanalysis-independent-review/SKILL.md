# Worldanalysis 独立教材验收

由项目指定的独立测试角色使用。沿[课程验收规范](../course-material-archive/acceptance.md)填写同版回执。

1. 确认候选正文、收件范围和配套的版本。先依据实收原件列关键知识、条件、操作及必须保留的实物，记录讲次、时码、页、工作表或档内成员，再打开生产事实清单逐项对照。
2. 先退回明显的坏链、错版、错绑和缺文件。双向核查教材遗漏及关键数字、单位、条件、归属和必要配图。历史修订聚焦变化及受影响依赖。无法核实的范围注明实际影响。
3. 在隔离阅读环境从主教材打开必要配套，按实际情况核对全文复制、原格式、表格或媒体。核输入、入口、设置和结果，分别记录只读走查、隔离演示、未运行或无法验证。
4. 将原件先查结果、差额、跟做结果和附件实际打开情况写入同版回执所引用的证据。核当前版本和角色后签收或退回。清理资格使用单独的授权和保全门禁。
