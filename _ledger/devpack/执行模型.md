# Worldanalysis 执行模型与当前边界

依据：[原计划与验收](<../../worldanalysis_agent_devpack_20261110/06_IMPLEMENTATION_AND_ACCEPTANCE.md>)；开发包 SHA-256 `53be5ff31a5cfad54303a776eb92dccccd0834ca0d2bd59cb132c9069e1b4dc4`。原包19文件已零覆盖解压。本文是代码接续说明，不把设计、依赖可导入或合成测试当生产完成。

## 一、对象模型

唯一新业务台账为[SQLite](<../../整理结果/worldanalysis.sqlite3>)；历史075材料台账只读保留，不改成另一套活动任务系统。

`来源/来源修订 → 项目 → 资产/资产修订 → Job → Artifact/Block → Bundle → AnalysisRevision`

- 来源与项目分离；同项目允许多来源。项目的作者/主题/版本无证据不强行认定；不同作者不因同主题合并。
- 小原件按实际字节复制到项目原始材料，源不移动/删除。大媒体不走小文件入库，不以整片哈希作前置。
- Artifact 是真实字节；Block 是有来源类型和定位的文本/表格/图像出现位置/时间窗。相同图片字节可复用，多处出现分别登记。
- Bundle 使用不可变版本；分析任务绑定 bundle_id、revision、publish_id、模型与提示版本。换模型不触发重新采集。
- 开发验收记录不是第二套课程材料完成台账；所有生产任务仍以SQLite与已验产物为准。

实现：[台账/发布](<../../worldanalysis/store.py>)、[离线契约验证](<../../worldanalysis/contracts.py>)、[独立分析](<../../worldanalysis/analysis.py>)。

## 二、状态与权限模型

- 本地证据：注册 publish_id/staging → 文件写完/程序验收 → 同卷重命名 → SQLite published；启动时按同一publish_id对账。清单存在不等于可分析。
- 云盘转存：queued → **提交前持久化 submission_unknown** → submitted → 逐项目标身份/路径/数量/大小读回 → verified_complete；unknown不能盲重发。
- 分析：queued → running → partial/completed/blocked/failed。全部发现块都必须登记；文本范围回执与实际图像打开回执分开。
- 当前范围、真实授权、预算、provider与能力证据全部通过才可执行。Plan或模型自填grant字符串不能授权。
- 新云盘目标只允许 `/apps/教育分析学习/`。每次重新解析目标账号/ID/当前路径，分享ID不当用户盘ID；移出范围即拒读。
- 默认0新增商业预算、0外发、0百度AI新生成。无配置API明确blocked；当前Agent辅助模式不复制订阅令牌。
- 联系人保留原证据和未知归属，二维码/短正文/跨课程重复都不是删除授权。资料中的脚本、宏、程序不执行。

实现：[策略](<../../worldanalysis/policy.py>)、[来源与转存对账](<../../worldanalysis/acquisition.py>)、[限字节读取/Range/背压](<../../worldanalysis/reader.py>)。

## 三、自动路由模型

原生TXT/Office/XML/数字PDF → 按页/对象识别缺口 → 单页OCR/渲染 → 必要的Agent实际图像阅读。已有材料优先，不等待不存在的课件；失败项保留源、原因和补采入口。

媒体单独用有界读取/解封装、外层窗口、单GPU/CPU策略、字节/队列/缓存/RAM预算和检查点。混流不误报只传音频；静音仍可有视觉证据。OCR/ASR/观察/作者原文与推断分别标源。

实现：[文档](<../../worldanalysis/documents.py>)、[共享OCR](<../../worldanalysis/ocr.py>)、[媒体worker](<../../worldanalysis/media.py>)。媒体worker到通用Bundle的大素材整合仍需单独完成，不能把小文件Store API冒称百小时媒体入口。
